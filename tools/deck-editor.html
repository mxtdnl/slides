Deck text editor

Open a deck from your copy of the repository, change its words, and save it. Only text can change: headings, body text, speaker notes and activity content. Layout, colours and code stay exactly as they were. Nothing leaves this page.

No deck open.

How it works

  1. Open a deck file (courses/<course>/*.html or standalone/*.html) with the button above, or drop it on this page.
  2. Pick a slide on the left and edit its text. The preview shows the slide with your changes, and says whether the text still fits.
  3. Save writes the file back where it came from. Download copy saves a separate copy instead.
  4. Give the updated file to Claude Code with "here's the updated file". It follows EDITOR.md: it checks that only text changed, replaces the old version, and runs the tests.
